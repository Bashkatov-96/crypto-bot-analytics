# crypto-bot-analytics
Локальный проект на Python: сбор рыночных данных и новостей для аналитики и  возможной автоматизации на тестовой среде биржи (testnet). Реальная торговля  не заявлена; это исследовательский / учебный инструмент.
## Зачем CryptoPanic
Новости и заголовки используются как один из входов для контекста рынка 
(агрегация крипто-новостей), без публикации контента третьим лицам.
## Стек (планируется / частично)
Python, CCXT (биржевые данные), хранение в SQLite на этапе разработки.
## Конфиденциальность
Секреты и API-ключи не хранятся в репозитории — только через переменные окружения.
